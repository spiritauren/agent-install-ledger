# 安装台帐 · Install Ledger

**你的 agent 什么都能装。让它留下收据。**

一条三段链：**装前质询 → 装后台帐 → 定期复审。**
其中第三段——**在删东西之前停下来问人**——几乎没人做。

## 问题

AI agent 现在随时能装东西：`pip install`、`brew install`、`npm install`、下载一个二进制、`playwright install`。每一次都「只是装一个」。一年之后，你的硬盘里堆着一批你说不清用途的软件：

- 为一个一次性任务装的 700 MB 运行时，活到了今天
- 装过、用过、忘了，也没删
- 想删，但不确定谁在用它

问题从来不在「装」。**问题在于没人记账。**

## 为什么要一条链，而不是一个工具

每一段都有做得很好的工具：

| 段 | 已有工具 |
|---|---|
| 清理 | Mole、Pearcleaner、Uninstall |
| 依赖清单 | syft、Trivy |
| 安装前安全闸门 | SkillSpector |

但它们各占一块。**没有任何东西把「装前质询 → 装后台帐 → 定期复审」串成一条链——也没有任何东西在删除之前停下来问人。**

那条链就是这个仓库。

## 第一段 · 闸门

安装之前，agent 必须先回答四个问题。任一答「否」，就是：别装，另找办法。

1. **真的需要吗？**
2. **有更轻的替代吗？**（用户级胜过系统级；小包胜过大包）
3. **装完能删吗？**（临时用途 → `pip install --user`、缓存目录）
4. **登记了吗？**（落地那一刻就写——不要拖）

## 第二段 · 台帐

每个安装物一行，十一个字段。

| 字段 | 说明 |
|---|---|
| 名称 | 安装物名字 |
| 作用简述 | 这东西本身干嘛的（一句话，说人话） |
| 安装日期 | YYYY-MM-DD |
| 安装原因 | 为哪个项目/任务装的 |
| 关联项目 | 对应项目或任务 |
| 安装位置 | 绝对路径 |
| 占用空间 | 含依赖与缓存的真实占用（`du` 实测） |
| 留存性质 | 临时 / 阶段性 / 长期 |
| 可删除原因 | 为什么现在可以删（复审时填） |
| 卸载命令 | 怎么彻底删 |
| 状态 | 在用 / 可清理 / 已删除（+删除日期） |

注意大多数人会漏掉的那两个字段——**「可删除原因」和「卸载命令」**——正是让一年后还能清理的那两个。没有它们的台帐是**清单**，不是台帐。

## 第三段 · 复审

1. **扫描** —— 读台帐，并用 `du` 把每项重新量一遍。台帐永远是滞后的。
2. **报告** —— 逐项：作用、占用、对应项目完没完、留还是删、为什么。
3. **问人** —— 用户拍板。**在那之前什么都不删。**
4. **彻底删** —— 删**安装物本体 ＋ 它生成的工作文件**（缓存、临时数据）。**保留成果物。** 走系统废纸篓，不用 `rm`。

### 关键的那条线

> **删工作文件，留成果物。**

缓存目录是垃圾。那份缓存帮着做出来的报告不是。这条线错一次——连工具带一个月的工作一起删掉——人就会学会「再也不清理了」。

## 安装

凡支持 Skills 的 agent 皆可：

```bash
# Claude Code
mkdir -p ~/.claude/skills/install-ledger
curl -o ~/.claude/skills/install-ledger/SKILL.md \
  https://raw.githubusercontent.com/spiritauren/install-ledger/main/SKILL.zh-CN.md
```

不支持 Skills？把 `SKILL.md` 全文贴进 agent 的 system prompt，或项目规则文件（`AGENTS.md`、`CLAUDE.md`、`.cursorrules`）。

**存储随你。** 台帐可以是一个 Markdown 文件、一张表格、一个 issue、一个数据库。本规则只管**字段和流程**，不管你放在哪。合成示例见 `LEDGER.example.zh-CN.md`。

## 一个提醒

这是一条**给 agent 的规则**，所以只有 agent 真的读到它才管用。也就是说它必须放在 agent 本来就会看的地方——技能目录、system prompt、项目规则文件。**一条没人加载的规则是文档，不是机制。**

复审同理。如果永远没人说「复审安装」，第三段就永远不会跑，你手里又变回一堆。**这条链的好坏，取决于它最弱的那个触发点。**

## 不覆盖什么

- 包管理器自带的清单（`brew bundle dump`、`pip freeze`）——那些是用来**复现环境**的。这里管的是**问责**。
- 对装进来的东西做安全扫描——那是另一道闸门，而且别人做得更好。
- 强制力。这里没有任何东西能拦住一个铁了心的 agent；它只是让正确的做法成为阻力最小的那条路。
